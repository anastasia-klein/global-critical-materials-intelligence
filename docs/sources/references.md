# Reference sources and rights

The canonical ISO names and codes in geography_mapping.csv were generated and verified against **pycountry 26.2.16**. [pycountry](https://pypi.org/project/pycountry/) exposes Debian's pkg-isocodes ISO databases. The installed distribution declares **LGPL-2.1-only**; its [upstream licence](https://github.com/pycountry/pycountry/blob/main/LICENSE.txt) and notices remain applicable to upstream reference material. The project MIT licence covers original project contributions and does not relicense upstream data or dependencies.

Source-qualified IEA/Comext geography labels retain their original attribution. Manual alias and aggregate/residual classification rules are explicit in the seed and constrained to the observed source scope. Reference-package ISO coverage is not a claim of complete statistical country coverage or political recognition. No code is assigned by fuzzy inference.

The other five seeds contain reviewed project mappings for material families, exact IEA material definitions, selected traded products, mining/refining stages and source trade directions. They preserve the source labels and measurement restrictions from the source contracts. No additional observations are introduced by these reference tables.

IEA and Eurostat observations retain their upstream rights. See [source rights](../sources/licensing.md).
